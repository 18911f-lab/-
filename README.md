# 爆速分別！雑食どらごんと渋谷のゴミ山 🐲🗑️

渋谷区のゴミ分別ルールを楽しく学べる超高速反射神経バカゲー！  
大学のサービスラーニング課題（SDGs・30人以上の不特定多数への発信）向けに開発されたWebゲームです。

---

## 🎮 ゲーム概要
- **プレイ人数**: 1人
- **対応デバイス**: PC / スマートフォン（タッチ＆クリック対応）
- **操作キー（PC）**:
  - `1` / `Q`: 可燃ごみ
  - `2` / `W`: 不燃ごみ
  - `3` / `E`: 資源
  - `4` / `R`: 粗大ごみ
  - `5` / `Space`: 雑食どらごん（収集不可・家電リサイクル・危険物・隠したいもの）
- **SDGsターゲット**: 目標12「つくる責任 つかう責任」、目標11「住み続けられるまちづくりを」

---

## 🚀 GitHub Pages への公開手順
1. 本フォルダ（`gomi-sorting-game`）の内容をGitHubの新しいリポジトリにコミット＆プッシュします。
2. GitHubリポジトリの **Settings** > **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選択し、`main` ブランチの `/ (root)` を指定して保存します。
4. 数分後に発行されるURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）で世界中に即時公開されます！

---

## 🛠️ 主な機能・アーキテクチャ
- **完全静的Webアプリケーション**:
  - HTML5, CSS3, Vanilla JavaScript のみで構成（外部ライブラリ依存ゼロ）。
  - 通信不要・ロードゼロで瞬時に起動。
- **Web Audio API シンセサイザー**:
  - 外部のmp3ファイルを読み込まず、ブラウザ内部のオシレーターで効果音をリアルタイム生成。404エラーや音ズレの心配がありません。
- **渋谷区公式データ準拠（220品目以上収録）**:
  - 提供された渋谷区公式の分別CSVデータを内蔵。
  - ゴミ図鑑では、公式の分別注記（例：「汚れたプラは可燃へ」「30cm角以上は粗大ごみへ」など）が閲覧可能。
- **ローグライク＆やりこみ要素**:
  - プレイで獲得したエコポイント（EP）を使い、ショップで難易度別「新ゴミパック」やパッシブスキル（制限時間延長、ライフ増加）を解放可能。
  - ゴミ図鑑の正解数に応じた称号システム（見習い $\to$ プロ $\to$ マスター）。
- **X (Twitter) シェア機能**:
  - リザルト画面からスコアや珍死因（「テレビを可燃ごみに突っ込んで爆発」など）を1クリックで投稿可能。
